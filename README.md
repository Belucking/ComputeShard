# ComputeShard

ComputeShard is a distributed, scalable platform that leverages intelligent load-balancing and auto-scaling to power high-performance computing engines.

ComputeShard is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ComputeShard.git`
2. `cd ComputeShard`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
